# IPA-каталог

Статическая страница для публикации на Cloudflare Pages, GitHub Pages или любом обычном HTTPS-хостинге.

## Добавление приложения

Отредактируйте `apps.json`:

```json
[
  {
    "name": "Название приложения",
    "version": "1.0.0",
    "size": "120 МБ",
    "icon": "https://files.example.com/icon.png",
    "download": "https://files.example.com/app.ipa"
  }
]
```

`download` должен быть прямой HTTPS-ссылкой на файл. Сертификаты, Apple ID и закрытые ключи в этот проект не добавляются.

Для установки читателю нужен подписант Feather или ESign: сертификат импортируется в него, после чего IPA подписывается и устанавливается на устройстве.

## Локальная проверка

```bash
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080` из каталога проекта.

## Публикация

Загрузите содержимое каталога в Cloudflare Pages. IPA лучше хранить отдельно в объектном хранилище, а не в Git-репозитории.
